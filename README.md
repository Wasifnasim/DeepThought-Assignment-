Deterministic Reflection Agent

A decision tree-based reflection system that guides users through a structured end-of-day self-assessment. The application uses deterministic branching logic and signal-based state tracking to generate personalized reflections without relying on AI or LLMs at runtime.

Key Features
Deterministic decision-tree architecture
Fixed-choice behavioral assessment
Signal-based state tracking
Personalized reflection summaries
JSON-driven and easily extensible
No AI/LLM dependency during runtime
Reflection Dimensions
Locus of Control (Victim ↔ Victor)
Contribution Orientation (Entitlement ↔ Contribution)
Radius of Concern (Self ↔ Others)
Tech Stack
Python
JSON
Command Line Interface (CLI)
Run the Project
cd agent
python main.py
Objective

To transform psychological frameworks into a structured, transparent, and auditable reflection system that helps users develop self-awareness through deterministic decision trees and behavioral mode
